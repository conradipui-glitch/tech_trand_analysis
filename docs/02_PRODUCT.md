# Product

## Job to be Done

Когда пользователю Платформы ИИ-аналитики нужно понять, какие технологии только начинают формироваться внутри заданного направления, сервис должен выдать ранжированный список emerging trends и показать доказательства, почему они считаются зарождающимися.

## Вход

Произвольное технологическое направление, например:
- технологии в ИИ;
- новые материалы;
- квантовые коммуникации;
- технологии хранения энергии.

## Выход

TOP-15 трендов.

Карточка тренда:
- название;
- краткое описание;
- Emerging Trend Score;
- первый устойчивый период появления;
- динамика публикаций/патентов/implementation evidence;
- мотивация;
- преимущество;
- representative case;
- evidence;
- источники;
- объяснение скоринга.

## Не является целью MVP

- универсальная инвестиционная система банка;
- мониторинг всех банковских конкурентов;
- realtime stream processing;
- хранение полного корпуса мировых публикаций;
- генерация TOP-15 одной LLM без data/ML evidence.
