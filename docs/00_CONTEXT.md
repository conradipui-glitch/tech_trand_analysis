# Project Context

## Цель

Разработать ML-сервис для Платформы ИИ-аналитики банка: пользователь вводит технологическое направление и получает TOP-15 зарождающихся научно-технологических трендов с доказательной аналитикой.

## Обязательный результат

Для каждого тренда:
- название;
- мотивация: какую проблему решает;
- преимущество;
- кейс-пример: исследование или компания;
- источник;
- методология определения зарождаемости;
- измеримые признаки: первый период появления, число публикаций/патентов, рост, ускорение и др.

## Рабочая концепция MVP

1. Собирать минимальный набор high-signal источников.
2. Приводить всё к универсальной схеме `Observation`.
3. Дедуплицировать и семантически кластеризовать.
4. Обнаруживать новые/ускоряющиеся технологические кластеры.
5. Для кандидатов запрашивать исторический baseline.
6. Считать Emerging Trend Score.
7. Ранжировать TOP-15.
8. Делать targeted enrichment для кейсов и подтверждающих источников.

## MVP discovery sources

Приоритет — источники, показывающие действие вокруг технологии:
- патенты;
- GitHub;
- Hugging Face Hub для AI-направлений.

OpenAlex используется прежде всего как количественный и исторический датчик. Аналитические отчёты и сайты компаний — преимущественно validation/enrichment после обнаружения кандидата.

## Архитектурные принципы

- source-agnostic pipeline;
- incremental-first;
- local-first ML;
- source adapters → единая Observation schema;
- дорогие LLM только после дешёвой математической фильтрации;
- модели заменяемы через provider/router abstraction;
- targeted backfill вместо полного исторического архива;
- GitHub — source of truth проекта.

## Текущая стадия

Подготовка MVP: валидация источников, Observation schema и ML-пайплайна.
