# Chat ↔ Project Memory Protocol

## Source of truth

- GitHub — актуальное структурированное состояние проекта.
- Google Drive — тяжёлые первичные материалы, PDF, отчёты, evidence и deliverables.
- Чат — временный рабочий интерфейс.

## Bootstrap нового чата

В начале:
1. `docs/00_CONTEXT.md`
2. `docs/07_MVP_PLAN.md`
3. `docs/09_BACKLOG.md`
4. профильные документы — только по необходимости.

## После существенной работы

- обновить профильный документ;
- новое решение → `docs/08_DECISIONS.md`;
- статус задач → `docs/09_BACKLOG.md`;
- существенное изменение → `docs/10_CHANGELOG.md`;
- нерешённые вопросы → `docs/11_OPEN_QUESTIONS.md`;
- experiment/research result → `research/`.

## Что не сохранять

Не переносить в project memory весь диалог, черновые рассуждения и повторения. Сохранять только текущее состояние, решения, основания, результаты проверок и следующие действия.

## Формат ответа в чат

После записи достаточно короткого лога:
- какой файл обновлён;
- какое решение принято;
- какая задача закрыта/открыта;
- следующий логичный шаг.
