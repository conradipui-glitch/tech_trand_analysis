# Requirements

## Исходное требование

Необходимо разработать сервис для Платформы ИИ-аналитики банка, который позволит эффективно отслеживать зарождающиеся технологические тренды.

Пользователь вводит технологическое направление, например «технологии в ИИ».

Сервис возвращает TOP-15 зарождающихся научно-технологических трендов заданного направления.

Для каждого тренда должны быть представлены:
- мотивация;
- какую проблему решает;
- какое преимущество даёт;
- кейс-пример: исследование или компания, ведущая разработку;
- источник;
- методология определения зарождающегося тренда.

## Ресурсы по ТЗ

- открытые сайты;
- аналитические отчёты по технологиям и трендам;
- патенты;
- научные публикации.

## Итоговый продукт

ИТ-сервис на базе ML с вводом технологического направления и выдачей списка emerging trends с детальной аналитикой.

## Ограничения MVP

- разработка в соло;
- минимальная инфраструктура;
- расширяемость источников без пересборки аналитического ядра;
- путь от API-моделей к локальному ML/LLM-стеку;
- доказуемость результата важнее широты источников.
