**Status:** NOT STARTED

## Goal

Проверить минимальный набор high-signal sources для MVP.

## Candidates

### Patents
Проверить доступ, поля, incremental retrieval, historical counts и signal/noise.

### GitHub
Проверить discovery, created/updated dynamics, stars/forks/actors и rate limits.

Проверить model/dataset/space discovery и применимость к AI-related направлениям.

### OpenAlex
Проверить роль как historical and quantitative validation source.

## Required output

Таблица:
- provider;
- access;
- cost;
- limits;
- fields;
- incremental capability;
- historical capability;
- relevance;
- implementation complexity;
- verdict: MVP / later / reject.
