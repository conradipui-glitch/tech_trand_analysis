# Bootstrap Prompt for a New Chat

Ты работаешь над проектом **Tech Trend Analysis** — ML-сервисом обнаружения зарождающихся научно-технологических трендов для Платформы ИИ-аналитики банка.

## Источник истины

Не восстанавливай состояние проекта из истории чатов.

Основной источник истины — GitHub-репозиторий проекта.

В начале работы:
1. прочитай `docs/00_CONTEXT.md`;
2. прочитай `docs/07_MVP_PLAN.md`;
3. прочитай `docs/09_BACKLOG.md`;
4. остальные документы открывай только по необходимости.

Для архитектуры используй `docs/03_ARCHITECTURE.md`.
Для источников — `docs/04_DATA_SOURCES.md`.
Для методологии — `docs/05_METHODOLOGY.md`.
Для ML — `docs/06_ML_STACK.md`.
Для решений — `docs/08_DECISIONS.md`.
Для исследований — `research/`.

Тяжёлые исходные документы, PDF, отчёты и reference/evidence-материалы хранятся в папке проекта `Tech Trend Analysis` на Google Drive. Обращайся к ним только когда текущая задача требует первичного материала.

## Правило контекста

Используй минимальный достаточный контекст. Если решение зафиксировано в документах проекта, оно приоритетнее старой переписки. Не переоткрывай закрытый вопрос без новых данных.

## После работы

После существенного результата:
- обнови профильный документ;
- решение добавь в `docs/08_DECISIONS.md`;
- обнови `docs/09_BACKLOG.md`;
- существенное изменение добавь в `docs/10_CHANGELOG.md`;
- нерешённый вопрос добавь в `docs/11_OPEN_QUESTIONS.md`.

Не копируй весь разговор. Фиксируй только актуальное состояние, решения, основания, результаты экспериментов и следующие действия.

## Ответ в чат

После записи во внешнюю память дай короткий журнал изменений, например:
- `03_ARCHITECTURE.md` — обновлено;
- `08_DECISIONS.md` — добавлен ADR;
- `09_BACKLOG.md` — задача закрыта / следующая активирована.

Чат — интерфейс работы. GitHub — долговременная структурированная память проекта. Google Drive — архив первичных материалов и тяжёлых источников.
